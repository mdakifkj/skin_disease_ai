1. Project Objective

Dermatological disease classification presents complex computer vision challenges due to high intra-class variance in lesion morphology, varying skin pigmentation across Fitzpatrick phototypes, and heterogeneous photographic lighting conditions. This academic research project evaluates the feasibility and interpretability of transfer learning using modern Convolutional Neural Networks (EfficientNetB0) coupled with Gradient-weighted Class Activation Mapping (Grad-CAM).

2. Deep Learning Architecture

EfficientNetB0 Backbone

Pretrained on 1.4M ImageNet images. Uses compound scaling to balance network depth, width, and resolution, generating robust high-level visual representations.

Custom Dense Head

Features GlobalAveragePooling2D, Batch Normalization, and Dropout layers (0.35 & 0.25) to mitigate overfitting, feeding into a 7-class Softmax activation layer.

4. Severity Prediction Branch & Integrity

A core principle of this project is maintaining scientific integrity regarding pathology scoring:

Scientific Integrity Notice

Disease categories (e.g., Eczema vs Psoriasis) describe what condition is present, not how severe it is. Severity grading (Mild, Moderate, Severe) requires clinical scoring indices (such as EASI or PASI) and dedicated image labels. The severity model is isolated into a separate branch trained only when validated severity annotations are provided.

5. Visual Explainability (Grad-CAM)

To eliminate "black-box" decision opacity, the system implements Gradient-weighted Class Activation Mapping (Grad-CAM). By calculating the gradients of the predicted class score with respect to feature maps in the final convolutional layer (top_conv), the model highlights the precise lesion regions and edges that influenced the output classification.

6. System Limitations

  • Lighting & Specular Artifacts: Flash reflections, poor focus, or oblique angles can alter color saturation and feature extraction.
  • Phototype Bias: Models trained on predominantly light skin tones may exhibit reduced generalization across darker Fitzpatrick phototypes (Types IV-VI).
  • Context Confounders: Surgical ink, hair, or anatomical reference markers can introduce shortcut learning confounders.
  • Clinical Non-Equivalence: In-silico predictions must never be utilized as a medical diagnostic device or treatment prescription.
