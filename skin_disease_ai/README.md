## 📖 1. Project Objective

Skin disorders affect millions of individuals globally. This academic project demonstrates how deep transfer learning (using **EfficientNetB0**) paired with explainable AI (**Grad-CAM**) and a dual-branch classification pipeline can assist in computational dermatological research by:

1. Accepting and validating user-submitted skin lesion images.
2. Preprocessing images into normalized tensor formats ($224 \times 224 \times 3$).
3. Classifying skin conditions across 7 distinct dermatological target classes.
4. Estimating condition severity (*Mild*, *Moderate*, *Severe*) using a dedicated secondary branch.
5. Providing visual interpretability through Gradient-weighted Class Activation Mapping (Grad-CAM).
6. Persisting prediction and audit logs in an SQLite database with a modern, responsive web dashboard.

## 🔬 2. Disease and Severity Classes

### Target Disease Classes (7 Classes):
1. **Acne Vulgaris** (`acne`)
2. **Eczema / Atopic Dermatitis** (`eczema`)
3. **Psoriasis** (`psoriasis`)
4. **Rosacea** (`rosacea`)
5. **Fungal Infection / Tinea** (`fungal_infection`)
6. **Impetigo** (`impetigo`)
7. **Healthy / Normal Skin** (`healthy`) *(Negative control class)*

### Severity Classes (3 Classes):
- **Mild** (`mild`)
- **Moderate** (`moderate`)
- **Severe** (`severe`)

> ### 🛑 Crucial Limitation Regarding Severity Labels
> Publicly available dermatology datasets (e.g., ISIC, HAM10000, DermNet) provide disease classification labels, **not** clinical severity scores. To maintain scientific integrity:
> - **We do not pretend disease labels are severity ratings.**
> - The severity classification branch requires separate datasets with medically validated severity annotations.
> - The system architecture is built modularly so severity-annotated images can be placed into `severity_dataset/` and trained independently.

## 🧠 6. AI Model Training & Evaluation Workflow

### Phase 1: Preparing Datasets

1. **Disease Classification Dataset**:
   Place appropriately licensed dermatological images (JPG, PNG, WEBP) into the target class subfolders:
   ```text
   dataset/train/<class_name>/
   dataset/validation/<class_name>/
   dataset/test/<class_name>/
   ```
   *Classes*: `acne`, `eczema`, `fungal_infection`, `healthy`, `impetigo`, `psoriasis`, `rosacea`.

2. **Severity Classification Dataset**:
   Place severity-annotated images into:
   ```text
   severity_dataset/train/<mild|moderate|severe>/
   severity_dataset/validation/<mild|moderate|severe>/
   severity_dataset/test/<mild|moderate|severe>/
   ```

---

### Phase 2: Training the Disease Classifier

Run the transfer learning training pipeline:
```bash
python training/train_disease.py --epochs 25 --batch-size 32 --learning-rate 0.0001
```

**Optional Training Arguments**:
- `--epochs`: Total training epochs (default: `25`).
- `--batch-size`: Mini-batch size (default: `32`).
- `--learning-rate`: Initial Adam learning rate (default: `0.0001`).
- `--image-size`: Input image resolution (default: `224`).
- `--fine-tune`: Unfreeze top layers of EfficientNetB0 for fine-tuning after feature extraction.
- `--seed`: Random seed for reproducibility (default: `42`).

**Outputs Generated**:
- Model weights: `models/disease_model/efficientnet_b0_skin_disease.keras`
- Training curves plot: `results/disease/training_curves.png`
- Epoch metrics log: `results/disease/training_history.csv` & `results/disease/training_history.json`

---

### Phase 3: Evaluating the Disease Classifier

Evaluate model performance on the unseen test split:
```bash
python training/evaluate_disease.py
```

**Outputs Generated**:
- Classification report: `results/disease/classification_report.txt`
- Structured metrics JSON: `results/disease/evaluation_metrics.json`
- Confusion matrix heatmap: `results/disease/confusion_matrix.png`
- Per-class metrics bar chart: `results/disease/per_class_metrics.png`

---

### Phase 4: Training & Evaluating the Severity Model

1. **Train Severity Model** *(when severity-labelled images are present)*:
   ```bash
   python training/train_severity.py --epochs 25 --batch-size 32
   ```
   - Model weights saved to: `models/severity_model/severity_classifier.keras`
   - Training plots saved to: `results/severity/severity_training_curves.png`

2. **Evaluate Severity Model**:
   ```bash
   python training/evaluate_severity.py
   ```
   - Metrics saved to: `results/severity/severity_evaluation_metrics.json`
   - Confusion matrix saved to: `results/severity/severity_confusion_matrix.png`

## 📊 7. Evaluation & Reproducibility Guarantees

- **Class Imbalance**: The training script dynamically computes inverse class frequencies to weight the loss function:
  $$\text{weight}_c = \frac{N_{\text{total}}}{C \times N_c}$$
- **Reproducibility**: Explicit random seed control across Python, NumPy, and TensorFlow.
- **Explainability**: Integrated Grad-CAM visualization for anatomical feature localization.
- **Scientific Honesty**: No synthetic scores or fabricated accuracy values are emitted when datasets are pending.
