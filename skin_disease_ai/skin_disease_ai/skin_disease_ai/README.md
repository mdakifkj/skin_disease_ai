## 📖 1. Project Objective

Skin disorders affect millions of individuals globally. This academic project demonstrates how deep transfer learning (using **EfficientNetB0**) paired with explainable AI (**Grad-CAM**) and a dual-branch classification pipeline can assist in computational dermatological research by:

1. Accepting and validating user-submitted skin lesion images.
2. Preprocessing images into normalized tensor formats.
3. Classifying skin conditions across 7 distinct dermatological target classes.
4. Estimating condition severity (*Mild*, *Moderate*, *Severe*) using a dedicated secondary branch.
5. Providing visual interpretability through Gradient-weighted Class Activation Mapping (Grad-CAM).
6. Persisting prediction and audit logs in an SQLite database with a modern, responsive web dashboard.

## 🔬 2. Disease and Severity Classes

### Target Disease Classes (7 Classes):
1. **Acne Vulgaris** (`acne`)
2. **Eczema / Atopic Dermatitis** (`eczema`)
3. **Psoriasis** (`psoriasis`)
4. **Rosacea** (`rosacea`)
5. **Fungal Infection / Tinea** (`fungal_infection`)
6. **Impetigo** (`impetigo`)
7. **Healthy / Normal Skin** (`healthy`) *(Negative control class)*

### Severity Classes (3 Classes):
- **Mild** (`mild`)
- **Moderate** (`moderate`)
- **Severe** (`severe`)

> ### 🛑 Crucial Limitation Regarding Severity Labels
> Publicly available dermatology datasets (e.g., ISIC, HAM10000, DermNet) provide disease classification labels, **not** clinical severity scores. To maintain scientific integrity:
> - **We do not pretend disease labels are severity ratings.**
> - The severity classification branch requires separate datasets with medically validated severity annotations.
> - The system architecture is built modularly so severity-annotated images can be placed into `severity_dataset/` and trained independently.

## 🧠 6. Model Training Workflow

Once legally licensed datasets (such as DermNet NZ, ISIC Archive, or SD-198) are obtained:

1. **Organize Images**: Place images into `dataset/train/<class_name>/`, `dataset/validation/<class_name>/`, and `dataset/test/<class_name>/`.
2. **Train Disease Classifier**:
   ```bash
   python training/train_disease.py --epochs 25 --batch-size 32
   ```
3. **Evaluate Disease Classifier**:
   ```bash
   python training/evaluate_disease.py
   ```
4. **Train Severity Classifier** *(if severity data available)*:
   ```bash
   python training/train_severity.py --epochs 25 --batch-size 32
   ```
5. The web application will automatically detect trained `.keras` files and switch from demonstration mode to live inference with Grad-CAM overlays.
