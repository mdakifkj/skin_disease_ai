System Architecture

The architecture is designed with a modular separation of concerns spanning the frontend interface, secure ingestion pipeline, dual-branch deep learning inference, and explainability:

  • 1. Validation & Preprocessing: Incoming files are validated for MIME type, file size (≤16 MB), non-corruption, and dimensions. Images are normalized to RGB float32 arrays resized to \(224 \times 224\).
  • 2. Disease Classification Branch: Uses EfficientNetB0 initialized with ImageNet weights, augmented by Global Average Pooling, Batch Normalization, Dropout (0.3), and a Softmax output layer across 7 dermatological classes.
  • 3. Severity Classification Branch: Uses a dedicated 3-class classifier (Mild, Moderate, Severe) trained strictly on severity-annotated datasets to avoid conflating disease identity with pathology severity.
  • 4. Grad-CAM Explainability: Computes the gradient of the winning class score with respect to the last convolutional feature maps (top_conv), producing a visual localization heatmap.

Severity Dataset Requirements

A critical requirement in clinical machine learning is maintaining dataset integrity. Disease datasets (e.g., DermNet, ISIC) classify pathology category, not severity score. To train the severity branch, image datasets with validated clinical severity annotations (Mild, Moderate, Severe) must be placed in severity_dataset/.
